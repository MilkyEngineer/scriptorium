## Early conclusions (mobile)

- Image content blocks are for the **model**, not the person, on mobile: `page_image` stays useful for OCR-style questions, but anything the user must see needs a `/dl/` link (Markdown link, since bare URLs were not tappable) or a resource link.
- Tool **arguments** are small: the client would not construct a 64 KB string, and literals of 8 KB (mobile, Haiku) and 4 KB (web, default model) stalled it. Realistic inline input is a few KB; larger inputs by URL. Large inputs (documents to push, long Markdown) must come by URL (`push/fetch.py`) or in chunks; inline arguments are for short text only.
- Tool **results** of 64 KB text arrive intact.

## Early conclusions (web and Desktop)

- Resource links are not surfaced to the person at all on web, Desktop or mobile (the model does receive them as structured blocks on Desktop); images are visible only inside the expandable tool panel on web and Desktop. Neither is a way to hand a file to the user.
- The `/dl/` URL is the only cross-client delivery that works, and it is copy-paste on both web and mobile. Tools should return it as a Markdown link with a filename in the text so the model is more likely to relay it as a clickable link.

## Resulting defaults

| Setting | Default | Why |
| --- | --- | --- |
| Image results | Return the image block **and** a Markdown `/dl/` link with the filename in the same result | The model sees image blocks on every client; the person sees them only in the web/Desktop tool panel; Claude Code saves them to disk. The link is the only way to hand the person the file on mobile. |
| `page_image` default size | ~200 KB class (longest side 1024 px); `large` opt-in up to 1.5 MB | 1.5 MB worked everywhere but adds latency and context for no visible gain on mobile. |
| `MAX_INLINE_KB` (text results) | 32 KB per result, paginated | 64 KB arrives intact on claude.ai and Desktop, but Claude Code persists results at about 64 KB and shows a 2 KB preview; 32 KB stays inline everywhere. |
| Tool arguments | Realistic inline input is a few KB of ordinary text; `MAX_INLINE_KB` server ceiling 64; anything larger by URL (`push/fetch.py`) | The client would not build a 64 KB argument and stalled on a 4 KB literal (a pathological repeated-character string; ordinary Markdown of a few KB is normal model output). |
| `/dl/` links | Keep 10-minute signed URLs; emit as Markdown links with filename; never rely on resource links for the person | Resource links are invisible on web, Desktop and mobile; bare URLs are copy-paste on claude.ai and clickable only in terminals. Expiry is enforced (404). |
| `tools/list` per user | Admin tools appear for the admin without reconnect on every client | Verified with `admin_spike_ping` on mobile, web, Desktop and Claude Code; hiding from non-admins is covered by unit tests on the filter. |
